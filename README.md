# Kestrel Brand

Official logos, color palette, and banners for **Kestrel Labs**.

Kestrel Labs builds free, open-source tools for **Linux**, starting with **Debian-based distros and variants**. Source code for our apps is free under the GNU GPL v3.0 or later. **The Kestrel name and logo are trademarks** — see [TRADEMARKS.md](./TRADEMARKS.md).
